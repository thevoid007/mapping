Tentang Aplikasi

MAPPING adalah perencana rute perjalanan berbasis web yang berjalan langsung di browser.

  • 🗺 Peta menggunakan OpenStreetMap (Leaflet.js) — gratis, tanpa API key.
  • 🔎 Pencarian lokasi melalui Nominatim geocoding (OpenStreetMap).
  • 📦 Titik otomatis dihubungkan menjadi rute sesuai urutan input.
  • 💾 Rute tersimpan secara lokal di browser perangkat ini.
  • ⚡ Tidak memerlukan server PHP atau database untuk GitHub Pages.
